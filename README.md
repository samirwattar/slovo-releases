# Slovo releases

Android builds of **Slovo**, a Russian study app: daily plan, dialogue memorization, spaced repetition, grammar drills, and an optional AI conversation partner.

**Install:** open [the latest release](https://github.com/samirwattar/slovo-releases/releases/latest) on your phone, download the `.apk`, open it, and allow installing unknown apps. After that, the app updates itself from *Settings → App updates*.

This repository only holds release files; the app checks it for new versions.

Dictionary data, sentences and dialogues: [OpenRussian.org](https://en.openrussian.org/dictionary-data) contributors, CC BY-SA.
